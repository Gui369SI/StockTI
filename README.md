# StockTI - Sistema de Requisição e Controle de Insumos

Sistema interno para gestão de estoque e solicitações de suprimentos de TI e escritório.

## 📌 Documentação do Projeto
- `SPEC.md`: Especificações técnicas e requisitos do sistema.
- `TASKS.md`: Lista de tarefas para desenvolvimento.
- `design.md`: Guia de estilo e cores do projeto.
- `SCHEMA.sql`: Estrutura do banco de dados PostgreSQL (Supabase).
- `theme/`: Interfaces e protótipos visuais de cada tela.

## 🛠️ Tecnologias
- Frontend: HTML/CSS/JS (Google Stitch)
- Backend & Banco de Dados: Supabase
- Agente de Desenvolvimento: Google Jules
